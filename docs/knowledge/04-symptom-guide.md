# 常见症状对应科室指南

本指南帮助您根据症状初步判断应该挂哪个科室。

## 头部与神经系统
| 症状 | 建议科室 |
|------|----------|
| 头痛（反复发作） | 神经内科 |
| 头晕、眩晕 | 神经内科 或 耳鼻喉科 |
| 失眠、入睡困难 | 神经内科 |
| 记忆力减退 | 神经内科 |

## 心血管系统
| 症状 | 建议科室 |
|------|----------|
| 胸痛、胸闷 | 心血管内科 |
| 心慌、心悸 | 心血管内科 |
| 高血压 | 心血管内科 |
| 下肢水肿 | 心血管内科 或 肾内科 |

## 呼吸系统
| 症状 | 建议科室 |
|------|----------|
| 咳嗽（超过2周） | 呼吸内科 |
| 咳痰、咯血 | 呼吸内科 |
| 气喘、呼吸困难 | 呼吸内科 |
| 喉咙痛、咽部不适 | 耳鼻喉科 |
| 发热伴有咳嗽 | 呼吸内科 |

## 消化系统
| 症状 | 建议科室 |
|------|----------|
| 腹痛 | 消化内科（上腹部）或 普外科（急腹症） |
| 胃痛、反酸、烧心 | 消化内科 |
| 恶心、呕吐 | 消化内科 |
| 腹泻、便秘 | 消化内科 |
| 便血 | 消化内科 或 普外科 |
| 黄疸 | 消化内科 |

## 骨骼与关节
| 症状 | 建议科室 |
|------|----------|
| 关节疼痛、肿胀 | 骨科 或 风湿免疫科 |
| 腰痛、背痛 | 骨科 |
| 颈肩痛 | 骨科 |
| 骨折、扭伤 | 骨科 |

## 泌尿系统
| 症状 | 建议科室 |
|------|----------|
| 尿频、尿急、尿痛 | 泌尿外科 |
| 血尿 | 泌尿外科 或 肾内科 |
| 排尿困难 | 泌尿外科 |

## 皮肤
| 症状 | 建议科室 |
|------|----------|
| 皮疹、瘙痒 | 皮肤科 |
| 皮肤红肿、脱皮 | 皮肤科 |
| 脱发 | 皮肤科 |

## 妇科
| 症状 | 建议科室 |
|------|----------|
| 月经不调、痛经 | 妇产科 |
| 白带异常 | 妇产科 |
| 更年期症状 | 妇产科 |

## 儿科
| 症状 | 建议科室 |
|------|----------|
| 儿童发热 | 儿科 |
| 儿童咳嗽、感冒 | 儿科 |
| 儿童呕吐、腹泻 | 儿科 |

## 紧急症状（建议立即到急诊科）
- 突发剧烈胸痛
- 呼吸困难或窒息
- 大出血不止
- 突发意识丧失
- 严重外伤
- 中毒
