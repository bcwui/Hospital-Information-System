# 科室介绍

## 内科系统
- 心血管内科：诊治高血压、冠心病、心力衰竭、心律失常、心肌病等
- 呼吸内科：诊治肺炎、支气管炎、哮喘、慢阻肺、肺结节、肺癌等
- 消化内科：诊治胃炎、胃溃疡、肠炎、肝炎、胰腺炎、消化道出血等
- 神经内科：诊治头痛、头晕、癫痫、帕金森病、脑血管病、痴呆等
- 内分泌科：诊治糖尿病、甲亢、甲减、痛风、骨质疏松等
- 肾内科：诊治肾炎、肾病综合征、肾功能不全、尿毒症等

## 外科系统
- 骨科：诊治骨折、关节炎、椎间盘突出、骨质疏松、运动损伤等
- 普外科：开展胃肠、肝胆、甲状腺、乳腺等手术
- 泌尿外科：诊治肾结石、前列腺增生、膀胱肿瘤、泌尿系感染等
- 神经外科：开展脑肿瘤、脑血管病、脑外伤等手术
- 心胸外科：开展心脏瓣膜、冠心病搭桥、肺部肿瘤等手术

## 其他科室
- 妇产科：妇科炎症、月经不调、产前检查、分娩、产后康复
- 儿科：儿童常见病多发病诊治、儿童保健、预防接种
- 眼科：近视、白内障、青光眼、眼底病
- 耳鼻喉科：中耳炎、鼻窦炎、咽喉炎、听力障碍
- 皮肤科：湿疹、荨麻疹、痤疮、银屑病、皮肤过敏
- 口腔科：龋齿、牙周病、口腔溃疡、牙齿矫正
- 中医科：中医内科、针灸、推拿、拔罐、中药调理
- 急诊科：各种急危重症的紧急救治
