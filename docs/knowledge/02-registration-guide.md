# 就医流程指南

## 挂号方式
1. 现场挂号：持有效身份证件到门诊一楼挂号窗口
2. 线上预约：通过医院官网或App预约，支持提前7天预约
3. 电话预约：拨打010-12345679，工作日8:00-17:00

## 就诊流程
挂号/预约 → 分诊台报到 → 候诊区等候叫号 → 医生问诊 → 缴费 → 检查/取药

## 挂号须知
- 初诊患者请携带有效身份证件
- 预约患者请在预约时间前15分钟到达
- 如无法按时就诊请提前取消预约
- 累计爽约3次将被限制预约权限30天

## 退号规则
- 就诊前2小时以上可免费退号
- 就诊前2小时内退号收取20%手续费
- 超过就诊时间未退号，号源自动作废
