# 儿科常见疾病

## 小儿发热
体温≥37.5°C为发热。常见原因：上呼吸道感染、幼儿急疹、肺炎。处理：体温<38.5°C物理降温为主，≥38.5°C可遵医嘱用药。

## 小儿腹泻
常见原因：病毒感染（轮状病毒）、细菌感染、消化不良。注意：预防脱水，口服补液盐。危险信号：精神萎靡、尿量明显减少、哭无泪。

## 小儿肺炎
症状：发热、咳嗽、气促、鼻翼煽动。婴幼儿症状可不典型。是5岁以下儿童死亡的主要原因之一。

## 生长发育
正常范围存在个体差异。关注身高体重曲线、运动语言发育里程碑。定期儿童保健体检。

## 就医建议
- 3个月以下婴儿发热应立即就医
- 腹泻时继续喂养不要禁食，重点是补水
- 按时接种疫苗是预防儿童传染病最有效的方法
